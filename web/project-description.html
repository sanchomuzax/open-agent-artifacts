PROJECT DESCRIPTION · v0.2.2

A calm review layer between an agent and its deliverables.

Open Agent Artifacts gives AI agents a durable place to publish documents, code, diagrams, and other reviewable work. A person can open a stable link, browse a visual catalog, inspect an immutable version, select a passage, leave feedback, compare revisions, and request a deliberate next version. Markdown is shown as a real rendered document and HTML as a sandboxed visual page. Every artifact request is routed to the primary workspace; GitHub is an extra for source code. This project description itself is published as a pinned HTML artifact in the workspace.

What it provides

  • Stable artifact links and a searchable catalog.
  • Grid or grouped list views with visual previews.
  • Real rendered Markdown and sandboxed visual HTML.
  • Immutable versions with exact-parent concurrency checks.
  • Pinning, visible or hidden comments, and highlighted feedback.
  • A small CLI/API boundary for agent integrations.

How it works

  • The artifact service owns storage and review state.
  • Agents own content generation and explicit change requests.
  • SQLite keeps the first deployment local and inspectable.
  • Tailscale can provide private network access.
  • Hermes is an adapter, not a dependency of the core.

Safety boundary

Markdown is rendered through an allowlist parser. HTML is displayed in an opaque-origin sandbox with artifact scripts removed, no same-origin access, and no network or credential access. The product never executes arbitrary generated JavaScript, Python, shell commands, or npm packages.

Designed for evidence

Changes are tested before publication. Public releases contain only portable product material. Runtime data, private project context, credentials, and operational host details stay outside the public repository.

PROJEKTLEÍRÁS · v0.2.2

Nyugodt ellenőrzési réteg az agent és az elkészült munka között.

Az Open Agent Artifacts tartós helyet ad az agentek által létrehozott dokumentumoknak, kódoknak, diagramoknak és más ellenőrizhető munkáknak. Megnyithatsz egy stabil linket, böngészhetsz vizuális katalógust, megvizsgálhatsz egy változatot, kijelölhetsz egy részletet, visszajelzést adhatsz, összehasonlíthatod a verziókat, majd kérhetsz egy tudatosan elkészített új változatot. A Markdown valódi renderelt dokumentumként, a HTML sandboxolt vizuális oldalként jelenik meg. Minden artefaktum-kérés az elsődleges munkatérbe kerül; a GitHub csak a forráskód kiegészítője. Maga a projektleírás is pinelt HTML artefaktumként jelenik meg a munkatérben.

Amit nyújt

  • Stabil artefaktumlinkek és kereshető katalógus.
  • Grid- vagy csoportos listanézet vizuális betekintővel.
  • Valódi renderelt Markdown és sandboxolt vizuális HTML.
  • Immutábilis verziók és pontos szülőverzió-ellenőrzés.
  • Pinelés, látható vagy elrejtett kommentek és kiemelt visszajelzés.
  • Kis CLI/API-határ agent-integrációkhoz.

Hogyan működik

  • Az artefaktum-szolgáltatás kezeli a tárolást és a review-állapotot.
  • Az agent felel a tartalomért és a kért módosításért.
  • Az első telepítés helyi és áttekinthető SQLite-adatbázist használ.
  • A privát hálózati elérést Tailscale biztosíthatja.
  • A Hermes adapter, nem a mag működési függősége.

Biztonsági határ

A Markdown allowlistelt parseren keresztül renderelődik. A HTML opaque-origin sandboxban jelenik meg, az artefaktum-scriptek eltávolításával, same-origin, hálózati és hitelesítőadat-hozzáférés nélkül. A termék nem futtat tetszőleges generált JavaScriptet, Pythont, shell-parancsot vagy npm-csomagot.

Bizonyítékra tervezve

A változásokat publikálás előtt teszteljük. A publikus kiadások csak hordozható termékanyagot tartalmaznak. A futási adat, a privát projektkontextus, a hitelesítő adatok és az üzemeltetési hostadatok a publikus repón kívül maradnak.
