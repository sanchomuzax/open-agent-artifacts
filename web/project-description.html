PROJECT DESCRIPTION · v0.1.6

A calm review layer between an agent and its deliverables.

Open Agent Artifacts gives AI agents a durable place to publish documents, code, diagrams, and other reviewable work. A person can open a stable link, inspect an immutable version, select a passage, leave feedback, compare revisions, and request a deliberate next version.

What it provides

  • Stable artifact links and a searchable catalog.
  • Immutable versions with exact-parent concurrency checks.
  • Quoted, version-bound feedback and review status.
  • Safe text-first previews and bounded line diffs.
  • A small CLI/API boundary for agent integrations.

How it works

  • The artifact service owns storage and review state.
  • Agents own content generation and explicit change requests.
  • SQLite keeps the first deployment local and inspectable.
  • Tailscale can provide private network access.
  • Hermes is an adapter, not a dependency of the core.

Safety boundary

The first release displays artifact content as source text. It does not execute arbitrary JavaScript, HTML, Python, shell commands, or npm packages. Interactive previews require a separate isolation design and an explicit security decision.

Designed for evidence

Changes are tested before publication. Public releases contain only portable product material. Runtime data, private project context, credentials, and operational host details stay outside the public repository.

PROJEKTLEÍRÁS · v0.1.6

Nyugodt ellenőrzési réteg az agent és az elkészült munka között.

Az Open Agent Artifacts tartós helyet ad az agentek által létrehozott dokumentumoknak, kódoknak, diagramoknak és más ellenőrizhető munkáknak. Megnyithatsz egy stabil linket, megvizsgálhatsz egy változatot, kijelölhetsz egy részletet, visszajelzést adhatsz, összehasonlíthatod a verziókat, majd kérhetsz egy tudatosan elkészített új változatot.

Amit nyújt

  • Stabil artefaktumlinkek és kereshető katalógus.
  • Immutábilis verziók és pontos szülőverzió-ellenőrzés.
  • Idézett, konkrét verzióhoz kötött visszajelzés.
  • Biztonságos szöveges előnézet és korlátozott soros diff.
  • Kis CLI/API-határ agent-integrációkhoz.

Hogyan működik

  • Az artefaktum-szolgáltatás kezeli a tárolást és a review-állapotot.
  • Az agent felel a tartalomért és a kért módosításért.
  • Az első telepítés helyi és áttekinthető SQLite-adatbázist használ.
  • A privát hálózati elérést Tailscale biztosíthatja.
  • A Hermes adapter, nem a mag működési függősége.

Biztonsági határ

Az első kiadás az artefaktum tartalmát forrásszövegként jeleníti meg. Nem futtat tetszőleges JavaScriptet, HTML-t, Pythont, shell-parancsot vagy npm-csomagot. Interaktív előnézethez külön izolációs terv és explicit biztonsági döntés szükséges.

Bizonyítékra tervezve

A változásokat publikálás előtt teszteljük. A publikus kiadások csak hordozható termékanyagot tartalmaznak. A futási adat, a privát projektkontextus, a hitelesítő adatok és az üzemeltetési hostadatok a publikus repón kívül maradnak.
